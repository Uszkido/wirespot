WIRESPOT GUIDE

Connect the mobile app and web dashboard

Sign in to the same WireSpot workspace on both devices. The mobile app and web dashboard then share routers, vouchers, subscribers, settings, and reports through Cloud Sync.

1. Create or sign in to your accountUse the same account on the mobile app and this dashboard.
2. Configure Cloud SyncUse the deployed WireSpot API URL. Local testing uses http://127.0.0.1:8080.
3. Pair the mobile appOpen Cloud Sync in the app and use the same workspace sign-in or one-time pairing flow.
4. Sync and verifyPress Sync Now, then confirm the router fleet and voucher counts match.
ROUTER CONFIGURATION

Configure the router before connecting it

Use the guide for your vendor, then return to Router Fleet and run Test connection. WireSpot only applies changes after you review and confirm a setup plan.

MikroTik RouterOSCreate a dedicated least-privilege operator. Enable API-SSL on 8729 (prefer this over 8728), restrict access to your WireSpot agent/LAN, then enter the router host, port, username, and password.
Ruijie / ReyeeMake sure the gateway is adopted in its controller, create a scoped controller/API account, and use the controller URL, site, and token shown in the vendor portal.
OpenWrtKeep LuCI/ubus or SSH private, install and configure the supported captive-portal package, and create a scoped service credential. Do not expose LuCI or SSH directly to the internet.
Omada / UniFiConfirm the controller is online and the access points/gateway are adopted. Create a dedicated controller account or token and use HTTPS for the controller endpoint.
After connectionVerify the discovered identity, take a configuration backup, run a dry-run/preflight, and test one subscriber before enabling production changes.

Vendor APIs differ. If a control is marked unsupported, WireSpot will not pretend it succeeded; use the vendor controller or the guided command plan instead.

Frequently asked questions

Do I need a VPN?

Not for the cloud-agent workflow. The router or mobile agent makes an outbound connection. A VPN or trusted LAN is still recommended for direct RouterOS management.

What does PPPoE do?

PPPoE authenticates subscribers to the router. FreeRADIUS checks their username, password, plan, speed, expiry, and accounting. It is not a router-management tunnel.

Where do my vouchers and subscribers appear?

After both devices use the same signed-in workspace and Cloud Sync succeeds, records created on one device are synchronized to the other.

Why is my dashboard empty?

WireSpot does not show fabricated data. Add a router or complete Cloud Sync before live routers, users, telemetry, and reports appear.

How do I recover access?

Use Forgot password on the sign-in screen. Production deployments must have a configured identity provider and email delivery service.

Is it safe to expose RADIUS or RouterOS ports?

No. Keep UDP 1812/1813 and RouterOS API ports private. Use firewall restrictions, API-SSL, a trusted LAN, or the cloud agent.
